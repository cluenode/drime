D-Rime 개인정보처리방침

D-Rime Android 앱에서 처리되는 데이터와 이용자의 선택권을 안내합니다.

시행일: 2026년 8월 12일 최종 수정일: 2026년 9월 2일 적용 앱: D-Rime (com.drime.app)
핵심 요약
  • D-Rime은 개발자가 운영하는 별도 회원·수집 서버를 두지 않습니다.
  • 광고 SDK와 이용 행태 분석 SDK를 포함하지 않습니다.
  • 앱 오류와 응답 없음 문제를 해결하기 위한 제한된 기술 진단 정보는 Sentry로 전송될 수 있습니다. 웹 URL·제목·닉네임·검색어·쿠키·HTML·로컬 보관 콘텐츠는 진단 보고서에 포함하지 않습니다.
  • 대부분의 컴패니언 데이터는 이용자의 기기 안에 저장되며, 이용자가 직접 선택한 문서 내보내기·가져오기·공유만 외부 저장소 또는 수신 앱으로 전달됩니다.
  • D-Rime 1.0.13부터 회원 메모와 Google Drive 동기화를 제공하지 않습니다. 업데이트 전 로컬 메모와 원격 Drive 스냅샷은 데이터 손실을 막기 위해 자동 삭제하지 않습니다.
  • 최근 읽은 글의 고정은 글 본문을 저장하거나 DP 계정과 동기화하는 기능이 아니라, 기기의 기존 글 링크와 읽기 정보를 자동 정리에서 제외하는 로컬 기능입니다.
  • DVDPrime 웹 이용 과정의 로그인·게시글·댓글 등은 D-Rime 개발자 서버가 아니라 DVDPrime과 이용자 사이에서 처리됩니다.

D-Rime은 DVDPrime 웹사이트 이용을 돕는 비공식 컴패니언 앱이며, DVDPrime 또는 Google이 직접 운영하거나 보증하는 앱이 아닙니다.

2. 처리하는 데이터와 이용 목적

기능 처리되는 데이터 목적·처리 위치
DVDPrime 웹 이용 로그인 쿠키, 웹 저장소, 이용자가 열람하거나 입력한 게시글·댓글·검색어 등 웹 내용 공식 DVDPrime 화면 표시와 사이트 기능 제공을 위해 앱의 WebView와 DVDPrime 사이에서 처리됩니다. 아이디·비밀번호를 D-Rime의 별도 데이터베이스, 백업 또는 개발자 서버로 복사하지 않습니다.
이전 버전 잔존 데이터 과거 버전에서 저장한 회원 메모·라벨·변경 기록과 Drive 동기화 상태 1.0.13은 해당 데이터의 표시·편집·백업·동기화를 제공하지 않습니다. 업데이트 과정의 호환성과 안전한 로컬 초기화를 위해 앱 전용 저장소에 남을 수 있으나 개발자 서버로 전송하지 않으며, 앱이 새 Drive 요청을 만들지 않습니다. 데이터 손실을 피하기 위해 업데이트만으로 자동 삭제하지 않습니다.
최근 읽은 글·고정·이어보기 게시판·글 식별값, URL, 제목, 선택적 작성자 표시명, 댓글 상태, 읽은 시각, 제한된 스크롤 위치, 목록 복원 정보, 이용자가 선택한 고정 시각 읽음 표시와 이어보기를 위해 이용자가 선택한 보존기간 동안 기기에 저장됩니다. 일반 읽음 기록은 개수 상한 대신 보존기간으로 정리하고, 최근 화면은 최신 500개를 먼저 표시한 뒤 더 불러옵니다. 검색은 보존기간 전체의 제목·작성자·게시판 정보를 기기 안에서만 처리합니다. 글 고정은 최대 500개이며 DP 로그인 없이 사용할 수 있고 기존 글 링크와 읽기 정보만 유지하며, 본문을 오프라인 저장하거나 DP 계정과 동기화하지 않습니다. 회원 전용 원문은 다시 열 때 로그인이 필요할 수 있습니다. 민감 게시판은 별도의 이용자 동의 범위에서 저장된 기록만 고정 대상이 됩니다.
게시글 본문·댓글 전체 복사 이용자가 현재 보고 있는 일반 게시글의 본문 또는 선택한 댓글 한 건의 일반 텍스트 이용자가 복사를 명시적으로 선택한 경우에만 현재 WebView에서 Android 시스템 클립보드로 전달합니다. D-Rime의 데이터베이스·파일·백업·개발자 서버에는 저장하지 않으며, 화면이나 탐색 문맥이 바뀌면 처리 중인 내용을 폐기합니다.
활동·새 글·지켜보는 글 알림 알림 설정, 댓글·추천·구독 상태, 제한된 제목·작성자명·URL, 이용자가 저장한 게시판 검색 조건과 검색어, 마지막 확인 기준값, 최근 7일간 받은 키워드 글의 로컬 묶음 식별값, 지켜보는 글의 댓글 기준값·확인 시각·선택적 고정 시각 이용자가 해당 기능을 켠 경우 DVDPrime에 제한된 확인 요청을 보내고, 결과 기준값과 알림 대상을 기기에 저장합니다. 키워드 받은 글은 최대 20개 묶음·총 500개를 최근 7일 동안 보존하며, 이용자가 묶음 또는 전체를 비우면 알림 조건과 읽은 글 기록은 유지하고 해당 휴대폰 알림 경로만 함께 정리합니다. 지금 확인은 새 Android 알림을 만들지 않고 앱 안 받은 글만 갱신합니다. 원본 HTML과 로그인 쿠키를 별도 데이터베이스에 저장하지 않습니다. 지켜보는 글은 최대 30개이며 모두 고정할 수 있습니다. 고정하지 않은 글은 마지막 원문 열기 또는 새 댓글 감지 뒤 2일이 지나고 정상 확인에서 미확인 새 댓글이 없을 때 자동 해제됩니다. 고정은 자동 해제만 막고 확인 순서는 바꾸지 않습니다. 미확인 새 댓글이 있는 글은 원문을 열 때까지 자동 재확인하지 않으며, 마지막 활동 2일이 지난 고정 글은 하루 한 번 확인합니다.
키워드 차단 이용자가 등록한 차단 키워드, 사용 여부, 가리기·숨기기 설정 화면의 제목·본문·댓글을 기기 안에서 가리기 위해 로컬로만 처리됩니다. 차단 키워드는 DVDPrime 또는 개발자 서버로 전송되지 않습니다.
미디어 보관함 이용자가 보관한 이미지 파일, 파일 형식·크기·해시, 원문 글 식별 정보·URL, 선택적 제목·간단 메모·보관 시각 이용자가 명시적으로 보관한 미디어를 관리하기 위해 앱 전용 파일과 로컬 데이터베이스에 저장됩니다. 미디어 보관함은 이전 버전의 회원 메모용 Drive 스냅샷이나 메모 백업에 포함되지 않습니다.
앱 설정 시작 화면, 기능 켜기·끄기, 보존 기간, 알림·미리 불러오기 선택, 마지막으로 확인된 안전한 화면 이용자 설정과 화면 복원을 위해 기기에 저장됩니다.
오류 진단 오류·응답 없음의 종류와 스택 트레이스, 발생 시각, 앱 버전·빌드, Android 이름·버전·빌드, 기기 제조사·모델·CPU 아키텍처와 에뮬레이터 여부 앱 안정성 문제를 탐지하고 수정하기 위해 오류 발생 시 Sentry의 미국 리전으로 자동 전송될 수 있습니다. 설치 식별자·계정·요청 URL·메시지·사용자 동작 기록, 성능 추적·세션 리플레이·화면 캡처·첨부 파일은 전송하지 않도록 제한합니다.

이전 버전의 Google Drive 데이터

D-Rime 1.0.13은 Google Drive 연결·동기화·연결 해제 화면을 제공하지 않으며, appDataFolder를 읽거나 쓰는 새 요청을 만들지 않습니다. 이전 버전이 만든 암호화 스냅샷과 Google 계정의 기존 연결은 업데이트만으로 삭제하거나 철회하지 않습니다. 이용자는 아래 삭제 안내에 따라 Google Drive의 숨겨진 앱 데이터와 Google 계정 연결을 직접 삭제할 수 있습니다.

파일 저장·가져오기·공유

보관함 ZIP·암호화 잠금 보관함의 내보내기·가져오기, 이미지·게시글 문서 저장 및 공유는 이용자가 Android의 시스템 파일 선택기 또는 공유 화면에서 직접 대상을 선택한 경우에만 실행됩니다. D-Rime은 공유 수신자를 자동으로 고르거나 전송하지 않습니다. 최종 파일은 이용자가 선택한 저장소 또는 수신 앱의 개인정보처리방침에 따라 처리될 수 있습니다.

3. 외부 서비스와 데이터 전달

D-Rime의 기능 수행 과정에서 다음 외부 서비스와 직접 통신할 수 있습니다.

  • DVDPrime: 웹 로그인, 탐색, 검색, 게시글·댓글 등 사이트 기능, 이용자가 켠 활동·새 글 확인
  • Google Play: 이용자가 개발자 응원 구매 화면을 연 경우 상품·구매 상태 확인과 결제를 Google Play가 처리
  • 이용자가 선택한 문서 제공자·공유 대상: 파일 내보내기, 가져오기, 이미지 저장 또는 공유
  • Sentry: 앱 오류·응답 없음 보고서 수신과 안정성 문제 분석. 통신 과정에서 IP 주소와 IP에서 파생된 대략적인 지역 정보가 처리될 수 있으나, D-Rime Sentry 프로젝트는 신규 이벤트의 IP 주소 저장을 차단하고 지역 정보를 필터링하며 기본·추가 민감정보 스크러빙을 적용합니다.

D-Rime 1.0.13은 Google Drive에 새로 접근하지 않습니다. 이전 버전이 만든 Drive 앱 데이터와 계정 연결의 삭제는 이용자가 Google Drive 및 Google 계정 설정에서 실행합니다.

D-Rime 운영자는 이용자 데이터를 광고 목적으로 판매하지 않으며, 맞춤형 광고 또는 마케팅 프로파일 생성을 위해 제공하지 않습니다. 단, 법령에 따른 적법한 요구가 있는 경우에는 적용 법률에 따라 필요한 범위에서 대응할 수 있습니다.

4. Android 권한

  • 인터넷: DVDPrime 웹 이용, 이미지 요청과 제한된 오류 진단 전송
  • 네트워크 상태: 연속 읽기용 미리 불러오기를 Wi-Fi 등 이용자가 선택한 네트워크 조건에서만 수행
  • 알림: 이용자가 켠 활동·새 글 알림 표시(Android 13 이상에서는 별도 승인 필요)

위치, 연락처, 카메라, 마이크, 전화, SMS 또는 전체 저장소 접근 권한은 요청하지 않습니다. 백그라운드 예약 작업을 위해 Android WorkManager가 시스템 수준 권한을 병합할 수 있으나, 이 권한으로 위치·연락처·통화·문자 데이터에 접근하지 않습니다.

5. 보유 기간과 삭제 방법

  • 미디어, 최근 읽은 글, 지켜보는 글 및 알림 규칙은 해당 화면에서 개별 삭제할 수 있습니다. 최근 읽은 글의 고정 해제는 고정 시각만 지우고 해당 행을 일반 보존 정책으로 되돌립니다.
  • 최근 읽은 글은 이용자가 선택한 보존 기간에 따라 정리되며, 설정에서 전체 삭제할 수 있습니다. 고정한 글은 자동 정리에서 제외되어 명시적으로 고정을 해제하거나 개별·전체 삭제 또는 D-Rime 데이터 초기화를 실행할 때까지 더 오래 남을 수 있습니다. 민감 게시판도 별도 동의로 기록된 행을 고정하면 같은 예외가 적용됩니다.
  • D-Rime 데이터 초기화를 사용하면 읽음 기록, 앱 설정, 보관함과 이전 버전에서 남은 로컬 회원 메모를 포함한 앱 전용 데이터를 삭제할 수 있으며 고정한 글과 고정 상태도 함께 삭제됩니다. DVDPrime 로그인은 유지됩니다.
  • DVDPrime 사이트 데이터 초기화를 사용하면 WebView의 쿠키, 캐시, 웹 저장소와 탐색 상태를 삭제할 수 있으며 DVDPrime에서 로그아웃될 수 있습니다. 이 작업은 최근 읽은 글과 고정 기록을 삭제하지 않습니다.
  • 앱을 삭제하면 앱 전용 로컬 데이터가 삭제됩니다. 이용자가 별도로 내보내거나 저장한 파일은 앱 삭제 후에도 선택한 저장소에 남을 수 있으므로 이용자가 직접 관리해야 합니다.
  • D-Rime 1.0.13에는 Drive 연결 해제·원격 삭제 기능이 없습니다. 이전 버전의 원격 스냅샷을 삭제하려면 Google Drive 설정의 앱 관리에서 숨겨진 앱 데이터를 삭제하고, 필요한 경우 Google 계정의 서드 파티 연결에서도 D-Rime 권한을 삭제해야 합니다.
  • Sentry 오류 이벤트는 적용되는 Sentry 계정의 보존 기간이 끝나거나 운영자가 먼저 삭제할 때까지 보관될 수 있습니다. 보고서에는 이용자 계정이나 지속적인 기기 식별자를 넣지 않으며, 관련 문의는 개인정보 문의처로 받을 수 있습니다.

D-Rime은 자체 계정을 만들지 않습니다. DVDPrime 계정과 게시글·댓글 삭제, 이전 버전의 Google 계정 연결 및 Google Drive 앱 데이터 관리는 각 서비스가 제공하는 절차를 따라야 합니다.

단계별 절차와 삭제·보관 범위는 D-Rime 계정 및 데이터 삭제 안내에서 확인할 수 있습니다.

6. 데이터 보호

  • 지원되는 네트워크 통신은 HTTPS를 사용합니다.
  • 컴패니언 데이터는 Android 앱 전용 저장소에 보관합니다.
  • 이전 버전이 만든 Google Drive 스냅샷과 회원 메모 백업은 암호화된 형식이지만, 1.0.13에서는 새로 만들거나 읽거나 동기화하지 않습니다.
  • Android 자동 백업과 기기 간 자동 전송을 사용하지 않도록 앱 백업을 차단합니다.
  • 최근 읽은 글과 고정 기록은 이전 회원 메모 백업이나 Drive 스냅샷에 포함되지 않습니다.
  • 로그인 쿠키, 원본 웹 HTML, 아이디·비밀번호는 이전 회원 메모 백업이나 Drive 스냅샷에도 포함되지 않았습니다.
  • Sentry 전송 전에 이용자·요청·메시지·태그·추가 정보·화면 이동 기록과 상세 기기 상태를 제거하고, Sentry 서버에서도 IP 저장 차단과 민감정보 스크러빙을 적용합니다.

다만 어떤 전자적 저장·전송 방식도 절대적인 안전을 보장할 수는 없습니다. 앱과 Android, 연결된 서비스의 보안 업데이트를 적용하고 기기 잠금을 사용하는 것을 권장합니다.

7. 아동의 개인정보

D-Rime은 아동을 대상으로 설계된 앱이 아니며, 운영자가 아동의 개인정보를 별도로 수집하기 위한 기능을 제공하지 않습니다. DVDPrime 이용 가능 연령과 게시판별 이용 조건은 DVDPrime의 정책을 따릅니다.
