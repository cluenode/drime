D-Rime · iOS

계정·자료 삭제 안내

시행일: 2026년 11월 6일 · D-Rime iOS 1.0(10) 이상

별도 앱 계정은 없습니다

앱의 로컬 자료 삭제, 사이트 회원 탈퇴, 내보낸 파일 삭제는 서로 다른 절차입니다.

1. 로컬 자료

최근 글·보관함 항목은 각 화면에서 삭제할 수 있습니다. 전체 로컬 자료를 지우려면 앱 기능 → 앱 설정 → 진단·초기화 → D-Rime 데이터 전체 초기화에서 설명을 확인하고 실행합니다. 보관함 파일·폴더·메모와 읽기·검색·설정 등 앱 자료가 삭제됩니다. 중요한 자료는 필요하면 삭제 전에 직접 백업해 주세요.

이 동작은 DVDPrime 서버의 계정·작성 글·댓글이나 Safari 데이터를 삭제하지 않습니다.

2. 사이트 로그인·웹 저장소

앱 설정 → 진단·초기화 → DVDPrime 웹 데이터 초기화는 이 앱의 WebKit 쿠키·캐시·웹 저장소와 열린 페이지 기록을 삭제합니다. 로그아웃되며 작성 중인 입력과 새 창이 사라질 수 있습니다. 최근 글·로컬 보관함은 별도입니다.

3. DVDPrime 회원 탈퇴와 작성 자료

로그인한 뒤 사이트의 회원 탈퇴 기능에서 요청하고 사이트의 본인 확인을 직접 완료합니다. 앱 삭제·초기화는 탈퇴를 대신하지 않습니다.

탈퇴 후 아이디·닉네임과 게시물의 보유에 관한 설명은 DVDPrime의 현재 방침과 문의처를 확인해 주세요. 필요한 글·댓글은 탈퇴 전에 별도로 관리합니다.

4. 내보낸 파일·시스템 백업

ZIP·암호화 백업, 사진에 저장한 자료와 공유한 복사본은 각각의 저장소·수신 앱에서 관리합니다. 앱을 삭제해도 남을 수 있습니다. 일반 앱 자료의 시스템 백업은 iOS의 기기·백업 설정에서 관리합니다. 잠금 보관함 저장소는 시스템 백업에서 제외합니다.
