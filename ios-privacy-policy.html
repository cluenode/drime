D-Rime · iOS

개인정보처리방침

시행일: 2026년 11월 6일 · 적용 대상: D-Rime iOS 1.0(10) 이상

Android 앱은 기존 Android 개인정보처리방침을 따릅니다.

1. 앱과 사이트 계정

D-Rime은 DVDPrime의 비공식 읽기·보관 도구입니다. 별도 D-Rime 계정은 없습니다. 공개 글 읽기·최근 글·키워드 차단·보관함은 가입 없이 이용할 수 있습니다. 사이트 회원 기능은 DVDPrime의 원래 로그인·가입·댓글 화면을 사용합니다.

2. 기기에 보관하는 자료

  • 최근 글의 출처·제목·읽은 시각·위치·고정 상태와 선택한 본문·댓글 저장본, 검색 기록
  • 차단 키워드와 화면·탐색·저장 설정
  • 사용자가 보관한 미디어·문서·댓글·링크, 출처·파일 정보·시각, 폴더·메모·좋아요
  • 시스템 선택기로 직접 고른 사진·영상의 앱 전용 복사본

개발자 서버에 이 로컬 자료를 자동 업로드하거나 Drive에 동기화하는 기능은 없습니다. 일반 자료는 iOS와 기기 설정에 따라 시스템 백업에 포함될 수 있습니다. 잠금 보관함은 시스템 백업에서 제외합니다.

잠금 보관함은 앱 전용 저장소·기기 인증·자동 잠금으로 접근을 제한합니다. 별도 파일 암호화 저장소라고 설명하지 않습니다. 내보내는 .drimevault 백업에는 비밀번호 암호화를 적용합니다.

3. 웹 연결·로그인·외부 서버

웹 화면은 DVDPrime의 두 HTTPS 원점, 범위를 제한한 정적 미디어 서버와 Cloudflare 보안 요청을 사용합니다. 미검토 외부 HTTP(S) 요청·제3자 쿠키를 제한하고 과거 외부 웹 데이터와 알려진 광고 쿠키를 정리합니다. 광고 컨테이너 배치 자체를 제거하지는 않습니다.

DVDPrime 로그인·사이트 설정 유지를 위해 쿠키와 웹 저장소를 기기에 보관합니다. 연결 서버에는 IP·브라우저 정보·페이지/검색 요청과 사용자가 제출한 입력이 전달될 수 있습니다. 별도 앱 계정이나 자체 분석 SDK가 없다는 것이 외부 서버의 정보 처리가 없다는 뜻은 아닙니다.

대상처리와 목적
DVDPrime / 미디어 서버사이트 탐색·회원 기능·요청 처리·미디어 전달. 사이트 방침은 회원 닉네임·비밀번호·이메일과 접속 IP 처리를 안내합니다.
CloudflareIP·TLS/브라우저 신호·사이트 원점 등을 이용한 자동화된 악성 요청 판별과 보안 기능 개선.
정적 CDN / Imgur 파일게시글 미디어 표시와 선택한 자료 저장. 파일 요청 서버에 IP·브라우저·경로 등이 전달될 수 있습니다.

외부 서버의 보유 기간·권리 행사는 각 운영자의 정책·절차를 따릅니다. D-Rime 개발자는 해당 서버의 회원 자료·접속 로그에 직접 접근하거나 이를 삭제할 수 없습니다.

4. 외부 영상·파일·권한

YouTube·Instagram·X 등의 서비스 영상은 이용자의 선택으로 원본 서비스 앱이나 브라우저에서 엽니다. 앱 안에서 제공자 플레이어나 새 제공자 썸네일을 요청하지 않습니다. 직접 저장한 영상과 갤러리 영상은 기기에서 재생합니다. 외부 서비스를 연 뒤 정보 처리는 해당 서비스의 정책을 따릅니다.

파일 가져오기·내보내기·공유는 시스템 화면에서 사용자가 정한 항목·대상으로 실행합니다. 갤러리 가져오기는 선택한 항목을 복사하며 전체 사진 보관함 접근 권한을 요구하지 않습니다. 사진 저장, 사이트 사진·영상 촬영, Face ID는 해당 동작 때 iOS 권한을 사용합니다. 위치·연락처·광고 식별자 접근 기능은 없습니다.

선택한 파일 제공자·공유 앱은 전달받은 파일을 그 서비스 정책에 따라 처리할 수 있습니다.

5. 응원 구매·문의·진단

개발자 응원의 상품·결제·거래 확인은 Apple StoreKit에서 처리합니다. 신용카드 번호·Apple 계정 비밀번호를 D-Rime이 수집하지 않습니다. iOS 진단은 앱 버전·상태를 로컬에서 표시·복사하며 자동 전송하지 않습니다. Android Sentry 보고를 iOS에 적용하지 않았습니다.

직접 문의 이메일을 보내면 회신·문제 해결을 위해 해당 문의 내용을 처리합니다. 문의 처리에 필요한 동안 보관하며 법적 보존 의무가 없는 경우 목적 달성 후 삭제합니다. 개인정보 관련 삭제 요청도 아래 문의처로 보내실 수 있습니다.

6. 보유·삭제

최근 글은 선택한 보관 기간에 따라 정리하며 고정한 기록은 별도 삭제까지 남을 수 있습니다. 보관함 항목은 해당 화면에서 삭제합니다. 앱 설정 → 진단·초기화의 앱 데이터 초기화와 DVDPrime 웹 데이터 초기화는 별도 동작입니다. 앱을 제거해도 내보낸 파일과 서버 작성 자료는 남을 수 있습니다.

DVDPrime 탈퇴는 사이트 절차에서 요청합니다. 현재 사이트 방침은 부정 이용 방지를 위한 아이디·닉네임 보유와 작성 게시물의 유지 가능성을 안내합니다. 필요한 글·댓글은 탈퇴 전에 따로 관리해 주세요.
