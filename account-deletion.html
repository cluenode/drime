D-Rime 계정 및 데이터 삭제 안내

D-Rime Android 앱, DVDPrime 계정, Google Drive 앱 데이터를 구분하여 삭제하는 방법을 안내합니다.

앱: D-Rime (com.drime.app) 최종 수정일: 2026년 8월 12일
개인정보처리방침 삭제 문의
먼저 확인해 주세요
  • D-Rime 개발자는 별도의 D-Rime 회원 계정이나 사용자 데이터 서버를 운영하지 않습니다.
  • 앱에서 이용할 수 있는 DVDPrime 계정은 DVDPrime이, 선택적으로 연결한 Drive 데이터는 이용자의 Google 계정이 각각 관리합니다.
  • D-Rime 로컬 데이터는 앱 안에서 즉시 삭제할 수 있으며, 계정을 삭제하지 않고도 개별 데이터 또는 전체 로컬 데이터를 삭제할 수 있습니다.

1. D-Rime 로컬 데이터 삭제

회원 메모, 최근 읽은 글, 알림 규칙, 키워드 차단 설정, 미디어 보관함 및 앱 설정처럼 D-Rime이 기기에 저장한 데이터는 다음 절차로 삭제할 수 있습니다.

  1. D-Rime의 앱 메뉴에서 설정을 엽니다.
  2. 컴패니언 로컬 초기화를 선택하고 삭제 범위를 확인합니다.
  3. 확인 화면에서 초기화를 승인하면 D-Rime의 앱 전용 로컬 데이터가 삭제됩니다.

DVDPrime 로그인 쿠키, 웹 저장소와 웹 탐색 상태까지 지우려면 설정에서 DVDPrime 사이트 데이터 초기화도 별도로 실행해 주세요. 앱을 제거하면 앱 전용 로컬 데이터가 함께 삭제되며, D-Rime은 Android 자동 백업과 기기 간 자동 전송을 사용하지 않습니다.

2. DVDPrime 계정 삭제

D-Rime 안에서 로그인하거나 회원가입한 계정은 D-Rime 계정이 아니라 DVDPrime이 운영하는 계정입니다. D-Rime 개발자는 해당 계정, 게시글 또는 댓글을 직접 조회하거나 삭제할 권한이 없습니다.

  1. D-Rime 또는 웹브라우저에서 DVDPrime에 로그인합니다.
  2. DVDPrime의 회원 정보 또는 계정 설정 화면을 엽니다.
  3. 회원탈퇴를 선택하고 사이트가 요구하는 본인 확인 절차를 완료합니다.
  4. 메뉴를 찾을 수 없거나 탈퇴가 처리되지 않으면 DVDPrime의 공식 사이트 연락처를 이용합니다.
DVDPrime 계정 탈퇴 후 게시글·댓글·신고 기록 등의 삭제, 익명화 또는 보관 여부와 기간은 DVDPrime의 약관과 개인정보처리방침에 따릅니다. D-Rime 로컬 데이터와 Drive 앱 데이터는 DVDPrime 탈퇴만으로 자동 삭제되지 않습니다.

3. Google Drive 앱 데이터 삭제

이용자가 Drive 동기화를 켠 경우, 암호화된 동기화 스냅샷이 이용자 Google Drive의 숨겨진 앱 전용 영역(appDataFolder)에 저장됩니다. D-Rime의 Drive 연결 해제는 권한 연결을 정리하지만 기존 원격 스냅샷을 삭제하는 작업과는 다릅니다.

  1. 컴퓨터 웹브라우저에서 Google Drive 설정을 엽니다.
  2. 앱 관리에서 D-Rime을 찾습니다.
  3. 옵션을 열고 숨겨진 앱 데이터 삭제를 선택합니다.
  4. 필요하면 Google 계정의 서드 파티 연결에서도 D-Rime의 접근 권한을 삭제합니다.

삭제 후 Google 저장용량 표시에 반영되기까지 시간이 걸릴 수 있습니다. D-Rime 개발자는 이용자의 Drive 앱 전용 영역에 접근할 수 없으며 별도 서버 사본을 보유하지 않습니다.

4. 외부로 저장하거나 공유한 파일

시스템 파일 선택기로 내보낸 암호화 백업, 외부 저장소에 저장한 이미지, 다른 앱으로 공유한 파일은 D-Rime 앱 전용 저장소 밖에 있으므로 위 초기화나 앱 제거로 삭제되지 않습니다. 이용자가 선택한 저장소 또는 수신 앱에서 직접 삭제해야 합니다.

5. 삭제되는 데이터와 보관 범위

대상 삭제 결과 별도 보관 또는 예외
D-Rime 로컬 데이터 초기화가 완료되면 앱 전용 저장소에서 즉시 삭제됩니다. 외부로 내보내거나 공유한 파일은 포함되지 않습니다.
DVDPrime 계정·게시물 DVDPrime의 회원탈퇴 및 삭제 절차에 따라 처리됩니다. 보관 기간과 게시물 처리 방식은 DVDPrime 정책을 따릅니다.
Google Drive 앱 데이터 이용자가 Google Drive에서 숨겨진 앱 데이터 삭제를 실행합니다. Google의 처리·표시 반영 시간과 정책이 적용됩니다.
D-Rime 개발자 서버 사본 별도 회원·수집 서버가 없어 삭제할 서버 사본이 없습니다. 법령에 따른 적법한 요구가 있는 경우는 예외입니다.
